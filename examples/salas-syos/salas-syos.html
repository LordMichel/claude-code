Por que alguns blocos não mostram quem reservou

O Microsoft 365 entrega a agenda das salas como livre/ocupado para todo mundo, mas o assunto e o organizador só aparecem para quem participa da reunião. Por isso esta página nomeia as reservas em que você está e marca as demais como reservadas, sem nome. Para que todos vejam todos os nomes, o administrador precisa dar permissão de leitura no calendário de cada sala, com Set-MailboxFolderPermission -Identity "Sala X:\Calendar" -User Default -AccessRights Reviewer.

Salas cadastradas e como a página descobre cada uma

Para ler a agenda de uma sala o Microsoft 365 exige o endereço da caixa de recurso dela. Os apelidos vêm de nomes antigos (SalaPaulo… é a Super Easy), então não dá para adivinhar. Você não precisa procurar: sempre que alguém que usa esta página tiver convidado a sala para uma reunião, a página aprende o endereço e ele passa a valer para todos.
